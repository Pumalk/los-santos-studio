# Los Santos Studio

Одностраничный сайт автостудии в Улан-Удэ. Сайт помогает выбрать направление
установки, посмотреть ориентиры по стоимости и связаться со студией.

**Основные направления:** комфорт (магнитола и камера), атмосфера (контурная
подсветка салона), звук (динамики, усилители и сабвуферы).

> Сайт статический: HTML, CSS и JavaScript. Сборщик и установка npm-пакетов для
> локального запуска не требуются.

## Быстрые ссылки

- [Открыть сайт](index.html)

Подробный чек-лист этапов публикации находится в рабочей копии по пути
`temp/Чек-лист-публикации-сайта.md`. Папка `temp/` исключена из Git, поэтому
этот внутренний документ не входит в публичную поставку и будет доступен только
там, где его сохранят отдельно.

## Запуск на компьютере

Можно открыть `index.html` напрямую. Для корректной работы локальных ресурсов и
виджета карты удобнее запустить простой HTTP-сервер из корня проекта:

```powershell
python -m http.server 8000
```

Затем откройте в браузере <http://localhost:8000/>.

Чтобы открыть тестовую страницу с другого устройства в той же сети, запустите
сервер с привязкой ко всем сетевым интерфейсам:

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

На втором устройстве откройте `http://<локальный-IP-компьютера>:8000/`.
Используйте этот режим только в доверенной сети и остановите сервер после
проверки.

## Текущая публикация и хостинг

Сайт состоит из статических файлов. Для размещения не нужны серверное
приложение, база данных или сборка: хостинг должен отдавать `index.html`,
каталоги `css/`, `js/`, `libs/` и `media/`.

В репозитории используется ветка `master`. Если публикуете через GitHub Pages:

1. Откройте настройки репозитория: **Settings → Pages**.
2. Выберите **Deploy from a branch**, ветку `master` и каталог `/ (root)`.
3. Сохраните настройки и дождитесь завершения публикации.
4. Откройте выданный GitHub Pages URL и проверьте страницу и ресурсы.

Публикуйте только если именно эти настройки выбраны в GitHub. Относительные
пути к стилям, скриптам и изображениям рассчитаны на работу как в корне домена,
так и в подпапке GitHub Pages.

## Перед запуском на основном домене

- [ ] Указать фактический основной HTTPS-домен; настроить DNS, SSL и
      перенаправление с HTTP на HTTPS, а также единый вариант адреса с `www`
      или без него.
- [ ] Заменить адрес GitHub Pages в `og:url`, `og:image`, `twitter:image` и
      Schema.org; добавить canonical основного домена. Проверить карточку
      предпросмотра `media/logo/og-cover.png` по новому URL.
- [ ] Создать `robots.txt` и `sitemap.xml` для опубликованного адреса. Для
      одностраничного сайта достаточно указать главную страницу.
- [ ] Проверить телефоны, адрес, режим «ежедневно с 08:00 до 22:00 по
      предварительному звонку», карту и цены. Цены в интерфейсе указаны как
      стартовые и должны быть подтверждены компанией перед публикацией.
- [ ] Заменить иллюстрации галереи настоящими фотографиями работ с разрешением
      на публикацию либо оставить честное пояснение, что это иллюстрации.
- [ ] Подтвердить источник и право на публикацию каждого отзыва. Удалить
      неподтверждённые цитаты или оценки; не добавлять фиктивный рейтинг и
      количество отзывов.
- [ ] Не копировать `temp/`, `.git/`, черновики или внутренние материалы в
      публичный web-root. Проверить, что они не доступны по прямому URL.
- [ ] Проверить сайт на телефоне, планшете и desktop: меню, звонки, FAQ,
      изображения, клавиатурную навигацию, карту и отсутствие ошибок в консоли.
- [ ] Если подключаются формы, аналитика, рекламные пиксели или другие средства
      сбора данных, до их включения определить, какие данные собираются и как
      обрабатываются, и подготовить требуемые уведомления и согласия по
      применимым правилам.

Cookie-баннер и cookie-политику не следует добавлять автоматически «для
галочки»: сначала проверьте фактические cookies, аналитику и сторонние
инструменты, а затем определите необходимые меры с учётом законодательства и
реальных процессов компании. На сайте используется встроенный виджет 2ГИС и
подключаются шрифты Google Fonts; учитывайте эти сторонние запросы при оценке
конфиденциальности.

## Карточка компании в 2ГИС

Перед публикацией или редактированием карточки через официальный кабинет 2ГИС:

- Подтвердите права на существующую карточку; не создавайте дубликат без
  необходимости.
- Сверьте название, категорию, адрес, телефон, график и положение метки у
  здания и фактического входа.
- Укажите актуальные услуги и стоимость только в том случае, если компания
  готова её поддерживать; условия «от» должны быть ясными.
- Добавьте сайт на основном HTTPS-домене и фотографии, на публикацию которых
  получено разрешение.
- После модерации проверьте карточку, звонок, маршрут и переход на сайт.

Сайт использует интерактивный виджет 2ГИС с запасной ссылкой на карту, если
встроенная карта не загрузилась. Для его отображения посетителю требуется
подключение к интернету и доступность сервиса 2ГИС.

## Содержание и сопровождение

- **Контакты и цены:** меняйте в `index.html`; синхронно обновляйте информацию
  на сайте и в карточке 2ГИС.
- **Галерея:** изображения находятся в `media/gallery/`. Перед публикацией
  реальных работ оптимизируйте файлы и проверьте согласия на фото.
- **SEO и предпросмотр:** после смены домена проверьте canonical, Open Graph,
  Twitter Card, Schema.org и прямую загрузку OG-картинки.
- **Анимации:** предусмотрена обычная прокрутка на телефонах и поддержка
  `prefers-reduced-motion`; не удаляйте эту проверку при изменении эффектов.
- **Проверка качества:** используйте Chrome DevTools (Device Mode) и Lighthouse
  для оценки производительности, доступности, SEO и best practices.
- **Внешние сервисы:** проверяйте доступность 2ГИС и Google Fonts; локальные
  AOS и Font Awesome находятся в `libs/`.
